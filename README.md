# 複数動画 同期フレーム抽出ツール

複数の動画(8本程度を想定)を同じフレーム位置で同時再生・コマ送りし、**元動画の高画質なフレームを PNG として一括抽出**するデスクトップツールです。論文用の比較画像作成などを想定しています。

## 特徴

- 複数動画の**同期再生 / スライダーシーク / ±1フレーム送り**
- 動画の**ドラッグ&ドロップ追加**、複数選択、削除、全クリア
- **軽量キャッシュ(プロキシ)** を事前作成して、重い動画でもサクサク再生
  - FFmpeg が使えれば GPU(NVENC) / CPU で高速変換
  - 同時変換数をスループットに応じて**自動調整**(GPUが無い環境では自動でCPUモード)
  - 動画ごとの進捗(待機中 / 変換中 % / 完了)を表示
- 抽出は**プロキシではなく元動画**から行うため、画質は劣化しません
- 日本語パスにも対応した PNG 保存
- 抽出先フォルダをワンクリックで開くボタン
- 画面解像度に応じてウィンドウサイズ・プレビュー列数を自動調整

## 動作環境

- Windows 10 / 11
- Python 3.9 以上 (exe を使う場合は不要)
- (推奨) FFmpeg

## セットアップ(Pythonで実行する場合)

```powershell
pip install -r requirements.txt
python main.py
```

## FFmpeg のインストール(推奨)

プロキシ作成が大幅に高速化されます。未導入でも OpenCV で動作しますが遅くなります。

- Anaconda をお使いの場合: `conda install -c conda-forge ffmpeg`
- winget: `winget install Gyan.FFmpeg`
- 手動: <https://www.gyan.dev/ffmpeg/builds/> から取得し、`bin` フォルダを環境変数 `PATH` に追加

確認方法: `ffmpeg -version` が実行できればOKです。インストール後はアプリを再起動してください。
GPU(NVIDIA)を使う場合は最新のドライバが必要です。

## 使い方

1. 動画をウィンドウにドラッグ&ドロップ、または「➕ 追加」で登録
2. (任意) 「⚙ ① 軽量キャッシュ(プロキシ)を作成」
   - 動画と同じ場所の `.proxy` フォルダに軽量版が作られます
3. 「▶ ② リストの動画を読み込む」
4. 再生 / スライダー / ±1フレームで目的の位置へ移動
5. 「📸 元動画から現在のフレームを抽出」
6. 完了ダイアログまたは「📂 抽出フォルダを開く」で保存先を開く

### 出力先

- 「📁 出力先を選択」で指定したフォルダ
- 未指定の場合は、リスト先頭の動画と同じ場所の `extracted_frames`
- その中に `frame_<フレーム番号>_time_<秒>s/` が作られ、`<動画名>.png` が保存されます

## exe 化

```powershell
build_exe.bat
```

`dist\MultiVideoFrameExtractor.exe` が生成されます(PyInstaller 使用、単一ファイル)。

- 初回起動は展開のため数秒かかります
- **FFmpeg は exe に同梱されません**。必要に応じて利用するPCにインストールしてください(無い場合は起動時ではなく、プロキシ作成時に案内が出ます)
- ウイルス対策ソフトが未署名の exe を誤検知する場合があります
- 配布する場合は、起動が速い `--onedir` 方式もお勧めです(`build_exe.bat` の `--onefile` を `--onedir` に変更)

## 注意

- プロキシは「動画と同じ場所/.proxy/同名ファイル」で管理されます。動画を差し替えた場合は `.proxy` 内の該当ファイルを削除してください。
- 動画ごとにフレーム数が異なる場合は、最長の動画に合わせてスライダーが動きます(短い動画は終了後に空表示)。
